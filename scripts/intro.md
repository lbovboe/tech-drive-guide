## What We'll Be Covering

So if you look at the guide that's open on your screen, you'll see five sections:

We'll start with **scheduled tasks** — basically getting ChatGPT to do something automatically on your behalf every day, without you having to remember to ask. The example we'll use is pulling daily tech news, but the same idea applies to any recurring thing you want to stay on top of.

From there, we'll set up a **Custom GPT** — this is where you give ChatGPT a specific role, knowledge, and a set of instructions so it behaves like a specialist. We'll build one that reviews AWS architectures, but you can imagine doing the same for any domain your team works in.

Then we'll look at **Skills** — these are reusable prompts or workflows that you or your team can save and share. We'll go through two ways to build them: one through chat, using a CSV analyser as the example, and one through the editor form, with a Python code reviewer. The point here is consistency — instead of everyone writing their own prompts from scratch, you define the standard once and everyone uses the same thing.

And finally, we'll install a **SharePoint plugin**, which lets ChatGPT actually pull in content from your SharePoint — so you can ask questions about your documents without having to copy and paste anything.

We'll go through each one step by step. I'll demo it first, and then you can follow along at your own pace using the guide.
