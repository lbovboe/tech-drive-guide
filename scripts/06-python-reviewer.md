# Presentation Script — Use Case 6: Python Code Reviewer (Creating a Skill via Editor Form)

---

## Introduction

Lets build our last use case Python Code Reviewer. The idea is that instead of every developer writing their own review prompt or ask the senior to review your code. you define one consistent rubric that the whole team can use to review our code.

This is especially useful for teams where code review quality varies depending on who's doing it.

---
---

## Step 1 — Open the Editor


Go to **Plugins → Skills**, click the **+** button, but this time select **"Create with editor"** instead of "Create with chat".

---

## Step 2 — Fill in the Skill Form


This opens a structured form. We will fill in the form together. Get the form inputs from the hands-on guide.

There are three fields to fill in.

**First, the Name.** 
**Second, the Description.** 
**Third, the Skill Instructions.** It's a full review rubric — covering correctness, security, error handling, style, type hints, documentation, testing, and performance. The guide has a Copy button — use it to grab the whole thing and paste it into the SKILL.md field.

---

## Step 3 — Create the Skill


Once everything is filled in, click **Create** in the upper-right corner.

---

## Step 4 — Confirm the Skill


Go back to the Skills page and confirm that your Python Code Reviewer appears in the list. Then open a new skill chat.

---

## Step 5 — Test It


The guide has a snippet of test code — it's intentionally bad one. 

The output should follow the structured format from the rubric. It includes  blockers, should-fix items,  and a final verdict.

---

## Wrap-up

The Python reviewer it's not about replacing code review — it's about making sure the baseline is always consistent, no matter who's reviewing.
